Each answer is short text plus a few blocks from a small kit. Switch between the example questions to see the same parts combined in different ways.

TextA short answer with numbered citations that link to their sources..text(markdown, citations)
Message listMail rows, optionally in sections. With bulk actions, rows can be selected. Without them, each row gets one quick action like Reply..messages(sections, actions)
CardOne thing pulled from an email: a flight, invoice, event or delivery. A headline value, a few fields, the source email and actions..card(kind, hero, fields, source, actions)
QuoteThe exact sentences an answer relies on, highlighted, with sender and date..quotes([excerpt])
DraftAn editable reply or new message. Nothing is sent until you press Send..draft(to, subject, body)
ActionsA fixed set the app can run and undo: open, reply, archive, mark read, move, flag, snooze, unsubscribe, add to calendar, remind. The model only picks which ones to offer.
